**Status legend (allowed values only):**
- **VERIFIED** — executed runtime evidence exists (run log / result JSON) for the stated behavior. Documentation alone never yields this status.
- **PARTIALLY VERIFIED** — main path executed, but a sub-path, scenario, or claim is unevidenced or has a known defect.
- **IMPLEMENTED BUT NOT VALIDATED** — code exists; no executed evidence in this workspace.
- **NOT IMPLEMENTED** — absent by design or omission.
- **NOT APPLICABLE** — out of scope for software-integration verification.
